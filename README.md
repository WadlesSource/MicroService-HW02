# Задача 2: Брокер сообщений
Составьте таблицу возможностей различных брокеров сообщений. На основе таблицы сделайте обоснованный выбор решения.
Решение должно соответствовать следующим требованиям: 
- поддержка кластеризации для обеспечения надёжности, 
- хранение сообщений на диске в процессе доставки, высокая скорость работы, 
- поддержка различных форматов сообщений, 
- разделение прав доступа к различным потокам сообщений, 
- простота эксплуатации.
Обоснуйте свой выбор.
### Ответ:
<img width="1835" height="252" alt="image" src="https://github.com/user-attachments/assets/caad2bc8-544b-4555-9957-332ec64f8abc" /> <br>
RabbitMQ и Kafka - идеальный вариант. Выбор конечного решения будет зависеть от предпочтения команды или задач сервиса.  
Разница в брокерах в используемой модели (push/pull)  
RabbitMQ - push  
Kafka - pull  
Kafka выигрывает в масштабировании.  
RabbitMQ позволяет упорядочивать группы событий, что бы они не конкурировали за получение сообщений.
